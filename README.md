# 📖 记单词工具 MVP

一个纯前端的记单词网页应用，专为**初中生背单词**设计，可运行在**科大讯飞 AI 学习机 T20** 及手机/电脑浏览器上。

## ✨ 核心特色

- **刷视频式交互**：上下滑动切换单词卡片，像刷短视频一样背单词，上手零门槛
- **按单元学习**：首页可选择单元（Unit 1~8）或全部，支持按单元默写
- **艾宾浩斯曲线**：基于科学的间隔重复算法（1/2/4/7/15 天），在"快要忘记"时复习
- **看中文拼写**：默写检验真正记住，而非"看着眼熟"
- **零成本、离线可用**：纯前端，无服务器、无 API，数据存本地

## 🎯 学习流程

每天打开 App：
1. 系统自动算出今天**待复习**（到期的词）+ **新词**
2. 先复习、再学新词
3. 每张卡片：浏览信息 → 上滑进入默写 → 看中文打英文 → 对错判断
4. 答对推进复习阶段，答错退回重学，5 次全过即"已掌握"

## 📱 在讯飞学习机 T20 上使用

1. **家长放行网址**：在家长手机「讯飞AI学」App 里，找到「网址守护」，把本网页的网址加入白名单
   - 如果部署到阿里云，白名单里填你的域名（如 `http://你的公网IP`）
   - MVP 阶段本地用：把整个文件夹传到学习机，用浏览器打开 `index.html`
2. **打开浏览器**：学习机自带浏览器，输入网址或打开本地文件
3. **添加到桌面**（可选）：浏览器菜单 → 添加书签/桌面，变成 App 图标

> ⚠️ 学习机的家长管控会拦截娱乐类应用和未授权网址。本工具是网页，走浏览器白名单最稳妥。

## 🖥️ 在电脑上预览（开发/测试）

由于使用了相对路径加载 JS/CSS，直接双击 `index.html` 在部分浏览器下可能受 `file://` 协议限制。推荐起一个本地服务器：

```bash
# 方式一：Python（最常用）
cd "E:\coding-zhou\AI 编程\记单词工具"
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000

# 方式二：Node http-server
npx http-server -p 8000
```

## 🧪 助记方法说明（为什么这样设计能记住）

参考市面上主流工具（Anki、墨墨、不背单词、百词斩），记单词的底层逻辑是两件事：

1. **编码**（让单词第一次进入脑子）—— 靠多通道多角度。本工具每张卡片融合词根（举一反三）+ 联想（趣味深刻）+ 例句（用法语境）+ emoji（视觉）。
2. **巩固**（别让它溜走）—— 靠间隔重复（SRS）。这是唯一被科学验证、几乎所有成功产品都用的机制。

详见 `data/README.md` 的词库编写规范。
