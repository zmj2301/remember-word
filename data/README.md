# 词库导入说明

本目录用于存放词库数据，以及说明如何用 Excel 扩充词库。

## 一、当前词库（已生成）

词库**内置在 `js/dict.js`** 中，共 **575 词**，覆盖八年级上册 8 个单元（Unit 1~8），由本目录对应的 Excel 生成。

生成命令：

```bash
python -X utf8 tools/generate_dict.py
```

每个词包含：`unit`（单元）、`word`（单词/短语）、`phonetic`（音标）、`pos`（词性）、`meaning`（中文释义）。

> ⚠️ 不要手改 `js/dict.js`，请修改 Excel 后重新运行生成脚本。

## 二、Excel 列格式约定

当前使用的 Excel（`2026秋季八年级上册英语人教版单词表（整理版）.xlsx`）列结构：

| 列 | 字段 | 说明 | 示例 |
|----|------|------|------|
| A | 单元 | 如 Unit 1 | Unit 1 |
| B | 单词 | 英文单词/短语 | ancient |
| C | 音标 | 国际音标 | /ˈeɪnʃənt/ |
| D | 词性 | n. / v. / adj. 等 | adj. |
| E | 释义 | 中文意思 | 古代的；古老的 |

### 兼容性说明

- 生成脚本会**跳过**包含 `Vocabulary A–Z` 的 OCR 索引行（教材附录字母表，内容与正文重复或为脏数据）。
- 单词含 `sb / sth / (…) / ...` 等占位符时，默写判分会自动忽略这些占位符，学生只需输入短语主体。

## 三、助记方法说明

当前 Excel 词库不包含 emoji / 词根 / 联想 / 例句字段，学习卡片会自动隐藏这些信息块，只展示：单词、音标、词性、释义。
如需补充助记内容，可在 Excel 中增加列（emoji、词根、联想、例句、例句翻译），并同步扩展生成脚本。

## 四、开源词库推荐

- **ECDICT**（英汉词典开源数据）：https://github.com/skywind3000/ECDICT

  - 可按词频筛选初中常用词
