# 记单词工具 MVP 实施方案

## 一、范围与目标（本阶段只做 MVP）

做一个**纯前端网页 App**，能直接在科大讯飞 T20 学习机的浏览器里打开运行。**先不接后端、不做云同步**，所有数据存在学习机浏览器本地。目标是把"核心记忆体验"跑通、验证好用，体验对了再进入第 2 阶段接阿里云。

### MVP 必须包含
1. 上下滑动卡片（刷视频式交互）
2. 艾宾浩斯曲线复习（1/2/4/7/15 天间隔）
3. 看中文拼写英文（默写）
4. 本地存储学习进度（localStorage）
5. 词卡信息全覆盖：emoji图标 + 音标 + 释义 + 词根 + 联想 + 例句
6. 约 30 个初中词汇做演示，验证流程

### MVP 暂不做（留给后续阶段）
- 后端 / 云同步（第 2 阶段，阿里云 ECS）
- 家长端进度面板（第 3 阶段）
- 完整 1500 词库（先 30 词验证）

## 二、技术选型

| 项 | 选择 | 理由 |
|----|------|------|
| 框架 | **原生 HTML/CSS/JS**（不引框架） | 讯飞 T20 浏览器兼容性最稳、离线也能跑、加载快、无构建步骤 |
| 离线 | **可选 PWA**（manifest + service worker） | 学习机联网受限时仍可打开；MVP 先做基础版，PWA 作为增强 |
| 存储 | `localStorage`（JSON） | 单机使用足够，结构简单 |
| 依赖 | **零依赖**，不联网 | 100% 保证在学习机白名单下可用 |
| 词库源 | ECDICT 开源数据 + 你的 Excel 导入 | 开源打底，你的数据增强/覆盖 |

## 四、数据格式

### 1. 单词数据结构（每张卡片）
```json
{
  "id": "apple",
  "word": "apple",
  "phonetic": "/ˈæpl/",
  "pos": "n.",
  "meaning": "苹果",
  "emoji": "🍎",
  "root": "无明显词根，基础词",
  "mnemonic": "联想：苹果公司 Apple，手机就叫它",
  "example": "I eat an apple every day.",
  "exampleTrans": "我每天吃一个苹果。"
}
```

### 2. 学习进度结构（localStorage，按单词存）
```json
{
  "apple": {
    "stage": 0,              // 复习阶段：0=新词，1~5=艾宾浩斯5次，6=已掌握
    "box": 0,                // 同 stage
    "dueDate": "2026-07-29", // 下次到期日（首次=今天）
    "learnedDate": "2026-07-29",
    "history": [             // 每次默写记录
      {"date":"2026-07-29","result":"correct"}
    ]
  }
}
```

### 3. 你的 Excel 导入格式（后续做导入脚本）
约定 Excel 列（你照着填，脚本自动转成上面的 JSON）：
`单词 | 音标 | 词性 | 释义 | emoji | 词根 | 联想 | 例句 | 例句翻译`

## 五、艾宾浩斯间隔重复算法

固定间隔表（经典）：`[1, 2, 4, 7, 15]` 天
- 学新词 → `stage=0`，1 天后复习
- 每次默写**答对** → `stage+1`，取下一个间隔设 `dueDate`
- 每次默写**答错** → `stage` 退一格（不低于 0），`dueDate` 设为明天（重新来过）
- 过完 5 次 → `stage=6`，标记"已掌握"，不再进入复习队列

## 六、交互流程

### 每天打开 App：
1. 读取本地进度，计算今天要做的两件事：
   - **复习队列** = `dueDate <= 今天` 的词
   - **新词队列** = 还没学过的词（MVP 每天上限默认 10 个，可调）
2. 先做**复习**（到期词优先），再学**新词**

### 单张卡片流程：
```
正面（学习）：emoji + 单词 + 音标 + 释义 + 词根 + 联想 + 例句
    ↓ 上滑进入"默写"
默写：显示中文释义，弹出输入框，打英文
    ↓ 提交
判断：对比输入与正确拼写
    ├─ 正确 → "答对了！" → 记录、推进 stage
    └─ 错误 → 显示正确拼写 → 记录、stage 退格
    ↓ 上滑
下一张卡片
```

### 上下滑动手势：
- **上滑** = 进入下一张 / 进入默写 / 下一步
- **下滑** = 回看上一张（复习已学）
- CSS scroll-snap 实现整页吸附，手感接近刷短视频

## 七、讯飞 T20 使用方式（README 里写明）
1. 家长在「讯飞AI学」App 里把本网页网址加入**网址守护白名单**
2. 学习机打开自带浏览器，输入网址
3. （可选）浏览器菜单选"添加到桌面"，变 App 图标

## 八、验证标准（MVP 完成判定）
- [ ] 在普通电脑浏览器打开 index.html 能正常运行
- [ ] 卡片能上下滑动切换，手感流畅
- [ ] 新词正确显示全部 6 类信息（emoji/音标/释义/词根/联想/例句）
- [] 默写交互正常：看中文打英文，对错判断正确
- [ ] 艾宾浩斯算法正确：答对推进、答错退格、到期词自动进复习队列
- [ ] 关闭浏览器重开，学习进度不丢（localStorage 生效）
- [ ] 内置约 30 个初中词汇做演示
